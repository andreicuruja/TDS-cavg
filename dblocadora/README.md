# TDS-cavg
Avaliação PHP - Implementação do Sistema Autolocadora (BD2)


Em PHP implementem o sistema para uma autolocadora de automóveis, cujo banco de dados foi implementado na disciplina de BD 2, que contenha:

as classes em PHP equivalentes ao banco de dados criado;
uma página home (index.php ou index.html) estilizando-o, ou seja, utilizando CSS), com menu de navegação para a página de cadastro e o outro item do menu, apontando para a outra página que visualiza dados (mostrar o que foi inserido);
as páginas com os formulários de cadastros que precisas se conectar no banco e realizar a inserção nas tabelas;
a página com a visualização de todos os automóveis que foram cadastrados, aqui também precisa da conexão com o BD, mas ai utilizando o comando SQL select;
a página com a visualização de todos os automóveis que estão disponíveis e os que estão locados;
O trabalho precisa estar em uma estrutura de Pastas (raiz: Autolocadora e pastas de /img /css no mínimo). Esta estrutura de pastas precisa estar no GitHub e o link postado na tarefa.
